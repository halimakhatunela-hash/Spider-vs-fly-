# BBFS Spider Pathfinding Game

## Description
A spider vs Fly game in C that demonstrates the Breadth-First Search (BFS) algorithm for shortest path finding.

## Features
- Algorithm 
- BFS Pathfinding
- Maze with Obstacles
- Score System

## Controls
- W - Up
- A - Left
- S - Down
- D - Right
- Q - Quit

## Technologies
- C Programming
- BFS Algorithm
